# Structural equality of two grids (geometry only, not dtype).

Structural equality of two grids (geometry only, not dtype).

## Usage

``` r
grid_equal(a, b)
```

## Arguments

- a, b:

  `GridSpec` objects.

## Value

`TRUE` or `FALSE`.

## See also

[`grid_diff()`](https://belian-earth.github.io/garry/reference/grid_diff.md),
which describes how two grids differ.
