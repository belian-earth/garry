# Replace a node in place (for rewrite passes).

Replace a node in place (for rewrite passes).

## Usage

``` r
graph_replace(graph, id, node)
```

## Arguments

- graph:

  A `Graph`.

- id:

  Integer id of the node to replace.

- node:

  The replacement `Node`.

## Value

The replacement node, invisibly.
